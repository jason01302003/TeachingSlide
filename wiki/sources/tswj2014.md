## 書目

- W.-C. Lee, Y.-R. Shiau, Y.-H. Chung, L. Ding, "Single-Machine Scheduling to Minimize Total Completion Time and Tardiness with Two Competing Agents," *The Scientific World Journal*, Volume 2014, Article ID 596306, 9 pages。
- DOI：10.1155/2014/596306；檔案：`raw/TSWJ2014-596306.pdf`；開放取用（Creative Commons Attribution License）。

## 一句話

一台機器要同時服務兩個代理人（agent）的工作：第一個代理人希望自己的工作早完成、少延遲，第二個代理人要求自己的工作一件都不能延遲；本文用 branch-and-bound 求最佳解，並用兩種模擬退火求近似解 [TSWJ2014 Abstract]。

> 定位說明：本篇全文沒有資源限制，也沒有提到 relocation problem [TSWJ2014 全文]。依使用者的決定，它在本 Wiki 是獨立的分支，只透過單機排程、完工時間、NP-hard 等共通概念與其他頁面相連。

## 問題設定

- $n$ 個工作，每個工作屬於代理人 $AG_1$ 或 $AG_2$，有加工時間 $p_j$ 與交期 $d_j$ [TSWJ2014 §2]。
- 完工時間 $C_j$；延遲時間 $T_j=\max\{0, C_j-d_j\}$；$U_j=1$ 表示工作延遲，否則為 0 [TSWJ2014 §2]。
- 目標：讓 $AG_1$ 工作的「總延遲時間與總完工時間的加權組合」最小，條件是 $AG_2$ 的工作不得有任何延遲 [TSWJ2014 §2]。
- 三欄記號如下，其中 $0\le\theta\le 1$ 是兩個指標之間的權重 [TSWJ2014 §2]。

$$1 \;\Big|\; \sum_{j\in AG_2} U_j = 0 \;\Big|\; \sum_{j\in AG_1} \big(\theta T_j + (1-\theta) C_j\big)$$

- 作者指出，同一個代理人同時考慮多個目標的多代理人排程，在文獻中很少被討論 [TSWJ2014 §1]。

## 主要內容

| 主題 | 內容 | 位置 |
|---|---|---|
| 難度 | 沒有 $AG_2$ 的工作且 $\theta=1$ 時，問題退化成單機總延遲時間問題，那已經是 NP-hard，所以本問題也難 | [TSWJ2014 §3] |
| 支配性質 | 一個非相鄰的性質（Property 1）與九個相鄰兩工作的交換條件（Proposition 1–9），用來刪掉不可能最佳的分支 | [TSWJ2014 §3.1] |
| 可行性判斷 | 把剩下的 $AG_2$ 工作依交期由早到晚接在已排好的部分後面，只要有一個會延遲，這個分支就不可行 | [TSWJ2014 Property 2] |
| 下界 | 先把剩下的 $AG_2$ 工作盡量往後排（不延遲的前提下），再把 $AG_1$ 的工作填進空檔並允許切開，得到目標值的下界 | [TSWJ2014 §3.2] |
| 模擬退火 | 兩個版本：$SA_1$ 遇到不可行的鄰近解就重新產生；$SA_2$ 把 $AG_2$ 的延遲乘上懲罰係數加進目標函數 | [TSWJ2014 §4] |
| 實驗一 | $n=12$：代理人的工作比例 $P$（定義見待確認）與交期參數 $(\tau, R)$ 都顯著影響 branch-and-bound 的節點數 | [TSWJ2014 Table 1, Table 2] |
| 實驗二 | $n=12$：權重 $\theta$ 對節點數沒有顯著影響（$F=0.74$，$P$ 值 0.48） | [TSWJ2014 Table 3, Table 4] |
| 實驗三 | $n=16, 20, 24$：branch-and-bound 可在合理時間內解到 24 個工作，最耗時的一組平均 47.37 秒；作者表示兩種模擬退火的平均誤差在所有測試中都小於 1%（但表中有一組為 1.05%，見待確認） | [TSWJ2014 Table 5, §5] |
| 實驗四 | $n=100, 200$：$SA_1$ 的相對偏差與「得到較佳解的次數」都優於 $SA_2$，作者建議工作數多時使用 $SA_1$ | [TSWJ2014 Table 6, §5] |

## 實驗設定

- 程式以 Fortran 90 撰寫，在 Intel Core 2 Duo T7500 2.20 GHz 的個人電腦上執行 [TSWJ2014 §5]。
- 加工時間取 1 到 100 的均勻整數；交期取 $T(1-\tau-R/2)$ 到 $T(1-\tau+R/2)$ 之間的均勻整數，其中 $T$ 是全部工作的加工時間總和，$\tau$ 是延遲因子，$R$ 是交期範圍因子 [TSWJ2014 §5]。
- 每種參數組合隨機產生 100 個例子 [TSWJ2014 §5]。
- 當 $P$ 較大、$R$ 較小或 $\tau=0.75$ 時問題比較容易解，作者的解釋是 Property 2 與下界在這些情況下更有效 [TSWJ2014 §5]。

## 與先前研究的關係

- 多代理人排程由 Agnetis 等人以及 Baker 與 Smith 最早引入排程領域 [TSWJ2014 §1]。
- 作者舉的應用情境：衛星通訊中不同類型的封包、運輸基礎設施的使用權、維修作業與生產工作搶機台、研發部門與製造部門共用試作工場 [TSWJ2014 §1]。

## 待確認

> **待確認**：實驗參數 $P$ 的定義前後不一。第 5 節先說要研究「第二個代理人的工作比例 $P$」的影響，下一句卻說「考慮了 $AG_1$ 工作比例的三個值，即 $P=0.25, 0.5, 0.75$」。作者說 $P$ 越大越好解是因為 Property 2 更有效，而 Property 2 是關於 $AG_2$ 工作的，由此推測 $P$ 是 $AG_2$ 的比例，但這是推論，不是原文明講的 [TSWJ2014 §5]。

> **待確認**：第 5 節說兩種模擬退火在 $n=100, 200$ 的所有測試中「平均執行時間都小於 1 秒」，但 Table 6 中 $n=200$ 有幾組 $SA_1$ 的平均 CPU 時間超過 1 秒（例如 1.06、1.07、1.45）[TSWJ2014 §5, Table 6]。

> **待確認**：接受機率的規則寫成「當 $P(\text{accept}) > r$ 時接受」，其中 $r$ 是 0 到 1 的均勻亂數；另外控制參數 $\alpha = k/\beta$ 會隨迭代次數 $k$ 變大，使接受機率變小。這兩點是依原文字面整理，細節請對照原文 [TSWJ2014 §4]。

> **待確認**：第 5 節與結論都說模擬退火的平均誤差「在所有測試組合中都小於 1%」，但 Table 5 中 $(n, P, \tau, R) = (20, 0.5, 0.25, 0.50)$ 這一組的 $SA_1$ 平均誤差是 1.05%（同一組 $SA_2$ 為 0.96%）[TSWJ2014 §5, §6, Table 5]。
